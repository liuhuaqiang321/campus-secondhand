🎓 校园二手交易平台

本页面用于连接云端数据库。填写一次即可，配置会保存在当前浏览器，
后续所有人都通过该云端库共享数据。

如何获取这两项配置？
1. 打开 supabase.com 注册并新建一个免费项目
2. 先在 SQL Editor 中执行 supabase/schema.sql 建表脚本
3. 左侧菜单 Project Settings → API
4. 复制 Project URL 与 anon public 两项粘贴到上方
5. 另需在 Authentication → Providers → Email 中关闭 Confirm email
⚠️ 提示：此处配置仅保存在你自己的浏览器中。若希望他人打开网址时无需配置， 请直接编辑 js/config.js 中的 DEFAULT_CONFIG 填入同样的值。
